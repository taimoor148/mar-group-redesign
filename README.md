# MAR Group corporate redesign concept

Requires Node.js 20.9 or newer. Run `npm ci` and `npm run dev`. Run `npm run build` to create a production build in `.next/`.

The contact form validates input and prepares a mailto draft. Visitors send through their own email app. Direct submissions require a separate form service or backend.

The live MAR Group site establishes portfolio membership and company information. Linked venture sites support the descriptions. Project examples and photographs are illustrative. The contact section uses the published locality because the official homepage and About page list different street addresses.
